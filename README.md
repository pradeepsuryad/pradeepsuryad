# Pradeep Surya Dadi

Robotics engineer (MS Robotics, Northeastern University, 2026) building surgical and humanoid
robots end to end, from high-density PCBs and firmware to perception, SLAM and precision control.

## Projects
- [ActiveGuide](https://github.com/pradeepsuryad/ActiveGuide): surgical virtual fixtures enforced in joint space, one QP per control step, on a Franka Panda and a dVRK PSM in MuJoCo.
- [hierrl-tissue-retract](https://github.com/pradeepsuryad/hierrl-tissue-retract): hierarchical skill chaining vs. demonstration-guided RL for surgical tissue retraction.
- [surgical-endoscope-gaze-ik](https://github.com/pradeepsuryad/surgical-endoscope-gaze-ik): SE(3) Newton-Raphson IK driving a 7-DoF Franka Panda along an endoscope trajectory in MuJoCo.
- [Xr_quest2_Unitree](https://github.com/pradeepsuryad/Xr_quest2_Unitree): teleoperating a Unitree G1 in MuJoCo from a Meta Quest 2 on WSL2, built on Unitree's open-source stack.

Open source: merged contributions to Enactic's OpenArm (openarm_ros2, openarm_description).
